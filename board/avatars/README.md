# Web board model icons

The web board embeds these local PNGs at build time; it never requests vendor assets at runtime. Official product marks and favicons are centered on transparent 128×128 canvases. Marks belong to their respective owners and identify the products; they do not imply endorsement. The terminal intro uses separate assets.
